# Follow-up Templates

## Post-Discovery Call
Subject: Next steps — {company} + {your_company}
- Recap key pain points discussed
- Outline proposed solution approach
- Attach relevant case study
- Propose next meeting with clear agenda

## Post-Demo
Subject: {product} demo recap + next steps
- Link to recording (if available)
- Summarize features mapped to their needs
- Include ROI estimate
- Clear CTA: trial, proposal, or stakeholder meeting

## Post-Proposal
Subject: {company} proposal — questions?
- Highlight 2-3 key value points from proposal
- Address most likely objection preemptively
- Offer walkthrough call
- Set deadline context (pricing, availability)

## Re-engagement (Gone Silent)
Subject: Quick question about {pain_point}
- Share relevant industry insight or data point
- Reference their original pain point
- Low-pressure CTA (article, report, not a meeting)
