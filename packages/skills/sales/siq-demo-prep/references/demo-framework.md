# Demo Preparation Framework

## Pre-Demo Research
- Company size, industry, recent news
- Prospect's role and likely pain points
- Current tools/solutions they use
- Decision-making timeline

## Demo Structure (30 min)
1. **Opening (3 min)**: Confirm agenda, validate pain points
2. **Discovery recap (5 min)**: "Based on our conversation, you mentioned..."
3. **Solution walkthrough (15 min)**: Map features to their specific pain points
4. **Social proof (3 min)**: Relevant case study or metric
5. **Q&A + Next steps (4 min)**: Clear CTA

## Objection Prep Matrix
| Objection Category | Example | Response Framework |
|:-------------------|:--------|:-------------------|
| Price | "Too expensive" | ROI calculation + competitor comparison |
| Timing | "Not right now" | Cost of inaction + quick-win path |
| Competition | "We're looking at X" | Differentiation + migration ease |
| Authority | "Need to check with..." | Champion enablement materials |

## Demo Environment Checklist
- [ ] Clean demo data loaded
- [ ] Relevant use case configured
- [ ] Backup slides if live demo fails
